# RHierarchy

Editor-only Hierarchy window enhancer for Unity 2022.3+.

## Install

Package Manager → **Add package from git URL**:

```text
https://github.com/hnb-rabear/RCore.git?path=Assets/RCore.RHierarchy
```

## Settings

`RCore > RHierarchy Settings`. Toggle the whole tool or any single column, reorder columns by
drag, and set active/inactive tint colors. Settings live in `EditorPrefs` under the
`RHierarchy_*` keys, so they are per machine and survive package reinstalls.

## Columns

Separator/row shading, visibility toggle, component icons, child count, vertex count, tag, layer,
static flags. Each is independently toggleable; drag to reorder.
